# Grey Seasonal Model

MATLAB implementations of grey seasonal forecasting models.

## Repository structure

- `01_Data_Generation_Model/`: data-generation operators and related utilities.
- `02_Grey_Seasonal_Linear_Model/`: linear grey seasonal models.
- `03_Grey_Seasonal_Nonlinear_Model/`: nonlinear grey seasonal models.
- `04_Grey_Seasonal_Coupled_Model/`: coupled grey seasonal and machine-learning/statistical models.

Each model is intended to be provided as an independently callable MATLAB `.m` file. The repository will document required inputs, outputs, and dependencies for each implementation.
